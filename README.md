# ChordPro → RTF Converter

![Latest release](https://img.shields.io/github/v/release/Sailor9060/chordpro-to-rtf)

**[⬇ Download the latest release](https://github.com/Sailor9060/chordpro-to-rtf/releases/latest)** — grab `ChordProToRTF.exe`, no install needed.

A small Windows GUI app that takes a ChordPro song file (`.cho`, `.crd`,
`.pro`) and splits it into two clean RTF documents:

- **Lyrics file** — just the words, chords and tab/grid notation stripped out
- **Chords file** — just the chord symbols, words stripped out

Section labels (Verse, Chorus, Bridge, ...) and comments are kept in both,
so you still get a readable, organized sheet — just without whichever half
you don't need.

## Features

- Drag-and-drop a ChordPro file onto the app, or onto a Desktop shortcut
- Generates both files in one click, or just one if you untick the other
- Handles custom section names, chord grids/tab blocks, and Unicode text
- Portable — single `.exe`, no install, no account, no ads
- Optional install script to place it in `C:\Program Files` and add it to
  your PATH
